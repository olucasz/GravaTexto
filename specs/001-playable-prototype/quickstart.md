# Execução e revisão local
`npm ci`, `npm run dev`, abrir http://127.0.0.1:5173.
`npm run build` gera dist; `npm run preview` serve a build sem painel de desenvolvimento.

## Percurso com Lucas
1. Começar Primeiros versículos. Ler os dois textos, trocar a seleção antes de verificar e concluir.
2. Recarregar durante uma seleção e durante feedback; retomar sem nova avaliação.
3. Abrir Confiança e cuidado. Praticar lacunas e peças extras; tocar uma peça montada para devolver.
4. No painel, abrir as nove famílias pela galeria isolada. Iniciais usam banco; digitação normaliza acentos/pontuação. A preferência da jornada permite digitação em revisões avançadas.
5. Testar cenários de erro cedo/tarde, revisões vencidas, tudo em dia e armazenamento indisponível.
6. Avançar relógio: preservar sessão mantém seu relógio capturado; encerrar arquiva. Voltar ao perfil real recupera dados normais.
7. Exportar JSON; conferir mode, schema_version, sessões, tentativas e progresso por dimensão. Reset remove somente o perfil selecionado do GravaTexto.
8. Rever fonte/licença, notas editoriais e distratores antes de qualquer piloto.

## Validação
`npm run content:check`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:e2e`, `npm run build`.
Playwright requer `npx playwright install chromium webkit`. Testes cobrem 360/390/1440 px, reflow equivalente a zoom 200%, teclado e movimento reduzido. Testar zoom nativo e leitor de tela real manualmente antes do piloto.

## Piloto sugerido
Após revisão com Lucas, 3–5 pessoas percorrem uma jornada sem instrução externa. Observar compreensão, erros de interação, leitura do feedback e retorno no dia seguinte. Exportação é local e voluntária. Não interpretar o piloto como comprovação pedagógica.
